# Platform artwork generation

These console renders were generated with Codex's built-in `image_gen` tool.
Each call used `atari_7800.webp` as a style reference and requested a transparent
background (`transparent_background: true`). The selected PNG outputs were
resized to 480 × 320 and converted to lossless WebP, preserving alpha, to match
the existing platform artwork. The console is the main subject in each image.

This records the prompts for the three images added in this update; it is not
a provenance record for the older artwork in this directory.

## `sega_sg1000.webp`

```text
Use case: product-mockup
Asset type: transparent hardware artwork for a game library platform card, landscape 3:2.
Primary request: an accurate Sega SG-1000 original 1983 console, with the complete console body prominently visible and a small SJ-200 joystick beside it.
Subject: original ivory rectangular Sega SG-1000 console, dark charcoal top panel, long black cartridge slot at the rear of the top, restrained blue and red accents, original wired black joystick with red button. The console occupies at least 75 percent of the group; the joystick is secondary.
Style/medium: polished realistic studio product render matching the supplied Atari artwork's clean materials and subtle blue-violet edge highlights. Input image is a style reference only; do not copy its console design.
Composition/framing: elevated front three-quarter view, entire console and controller in frame, centered, comfortably filling a landscape 3:2 canvas, generous transparent margin, no cropped edges.
Scene/backdrop: genuine transparent background, no floor or scene.
Lighting: soft studio key light, subtle blue and violet rim lighting, clear readable hardware details on dark app backgrounds.
Constraints: historically recognizable SG-1000 main console housing; no controller-only image; no Atari hardware, no display text, no captions, no watermark, no surrounding props.
```

## `atari_5200.webp`

```text
Use case: product-mockup
Asset type: transparent hardware artwork for a game library platform card, landscape 3:2.
Primary request: an accurate original Atari 5200 SuperSystem console with the complete console body prominently visible and one original keypad joystick controller beside it.
Subject: large broad wedge-shaped Atari 5200 black console, wide brushed silver metal top stripe with fine rainbow accent and Atari 5200 marking, black recessed cartridge slot on the upper surface, smoky dark rear controller-storage cover, sloping front housing; a small black original Atari 5200 joystick controller with numeric keypad, short stick and red side buttons at the side. The console occupies at least 75 percent of the group; controller secondary and not obscuring the main console.
Style/medium: polished realistic studio product render matching the supplied Atari artwork's clean materials and subtle blue-violet edge highlights. Input image is an Atari 7800 style reference only; render a different historically accurate Atari 5200.
Composition/framing: elevated front three-quarter view, entire console and controller in frame, centered, comfortably filling a landscape 3:2 canvas, generous transparent margin, no cropped edges.
Scene/backdrop: genuine transparent background, no floor or scene.
Lighting: soft studio key light, subtle blue and violet rim lighting, clear readable hardware details on dark app backgrounds.
Constraints: unmistakable Atari 5200 console housing; no controller-only image, no Atari 2600 or 7800 console, no display text, no captions, no watermark, no surrounding props.
```
