# Design tokens

Generated by `pnpm --filter @caskade/tokens build` from `packages/tokens/tokens/`. Do not edit.

Every token is a CSS custom property. Themes set them in `tokens.json`; see
[the theming contract](README.md). Override sets: `density-compact`, `effects-reduced`, `mode-console`, `motion-reduced`, `paint-cpu`, `reduced-motion`, `reduced-transparency`.
